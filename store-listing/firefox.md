# Firefox Add-ons (AMO) submission

The Firefox package is built from the same source tree as the Chrome one.
`npm run package` writes `dist/scam-detector-<version>-firefox.zip`, whose manifest is
generated by `tools/firefox-manifest.js` (run `node tools/firefox-manifest.js` to print it).
Submit at https://addons.mozilla.org/developers/ → **Submit a New Add-on** → *On this site*.

## Manifest values set for Firefox

| Key | Value | Why |
| --- | --- | --- |
| `browser_specific_settings.gecko.id` | `scam-detector@neteinstein.github.io` | AMO requires an ID for Manifest V3. It is permanent once the first version is uploaded: never change it. |
| `browser_specific_settings.gecko.strict_min_version` | `140.0` | Firefox ESR 140 is the first version that reads the data-collection declaration below. |
| `browser_specific_settings.gecko_android.strict_min_version` | `142.0` | First Firefox for Android that reads the data-collection declaration. |
| `browser_specific_settings.gecko.data_collection_permissions` | required: `browsingActivity` | See *Data collection* below. |
| `background.scripts` | the libraries from the `importScripts(...)` call in `src/background.js`, then `src/background.js` | Firefox runs Manifest V3 background code as a background script, not a service worker. |

## Listing fields

- **Name:** Scam Detector (from the manifest; max 50 characters).
- **Summary:** taken from the manifest description, identical to *Summary* in `listing.md` (AMO allows 250 characters).
- **Description:** paste *Detailed description* from `listing.md`. AMO accepts a limited Markdown subset; the bullet characters can stay as they are.
- **Categories:** Privacy & Security (desktop); Security & Privacy (Android).
- **Support website:** https://github.com/neteinstein/Scam-Detector/issues
- **License:** MIT.
- **Privacy policy:** paste the text of `privacy-policy.md` (AMO stores the policy text, not a URL).
- **Screenshots:** the PNGs in `assets/` can be reused.

## Data collection

AMO shows the categories declared in the manifest to users at install time. Keep this
in sync with `privacy-policy.md` (rule 1 of `AGENTS.md`).

| Category | Required or optional | What is sent |
| --- | --- | --- |
| `browsingActivity` | required | The registrable domain of each site visited, sent to `rdap.org` for the registration-date lookup (on by default, can be switched off in settings). Once the user enters their own Google API key, the full page address is sent to Google Safe Browsing. |

The PhishTank feed download sends no information about the user, so it needs no category.

## Source code

Not required: the package contains the repository files unchanged (no bundler, minifier
or transpiler), apart from the generated `manifest.json`. If a reviewer asks, point them
to the tagged commit on GitHub and `tools/firefox-manifest.js`.

## Notes to reviewer (paste into the submission)

> Scam Detector scores each page for scam signals locally. Broad host access is needed
> because scam pages can be on any domain; the content script reads the page in memory
> and sends nothing. Network requests: rdap.org (domain name only, for registration
> age), data.phishtank.com (public feed download, no user data) and, only if the user
> enters their own key, safebrowsing.googleapis.com. No remote code is loaded.
> The same code is published on the Chrome Web Store.

## Before every upload

- [ ] `manifest.json` version bumped (AMO rejects a version it has already seen).
- [ ] `npm test` passes and CI's *Lint the Firefox package* step (`web-ext lint`) has no errors.
- [ ] Loaded once with `about:debugging` → *Load Temporary Add-on* to check the banner,
      popup and settings.
